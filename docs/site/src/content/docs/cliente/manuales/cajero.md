title: Manual del cajero
---

## Abrir caja

1. Al iniciar el turno, abre la **sesión de caja** indicando el fondo inicial (USD).
2. Solo puede existir una caja abierta a la vez.

## Operar el POS

- Visualiza todas las **mesas** y sus cuentas abiertas.
- Puedes **añadir ítems** a cualquier mesa (los productos se enrutan solos a barra/cocina).
- Registra **abonos** parciales cuando el cliente adelante un pago.

## Cobrar una cuenta

1. Desde **Cuentas**, abre la cuenta de la mesa (o entra desde la vista de mesas).
2. Revisa el **resumen**: total, abonado y saldo.
3. Pulsa **Cobrar**: elige el método de pago y el monto (por defecto, el saldo completo).
4. Si el cliente paga con varias formas, añade líneas hasta cubrir el saldo.
5. Confirma: se genera la **venta**, el **comprobante** y el **ticket** para imprimir.

## Cerrar caja

1. Al terminar el turno, inicia el **cierre**.
2. Realiza el **arqueo contando solo billetes en dólares** ($1, $5, $10, $20, $50, $100);
   escribe `Enter` para pasar al siguiente billete.
3. El sistema muestra la diferencia entre lo esperado y lo contado.
4. Confirma para emitir el **reporte de cierre (Z)**.
