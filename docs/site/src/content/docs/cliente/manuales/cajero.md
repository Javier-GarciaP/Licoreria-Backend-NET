---
title: Manual del cajero
---

## Abrir caja

1. Al iniciar el turno, abre la **sesión de caja** indicando el fondo inicial.
2. Solo puede existir una caja abierta a la vez.

## Operar el POS

- Visualiza todas las **mesas** y sus cuentas abiertas.
- Puedes **añadir ítems** a cualquier mesa.
- Registra **abonos** parciales cuando el cliente adelante un pago.

## Cobrar una cuenta

1. Selecciona la mesa o cuenta.
2. Verifica el total, los abonos y el saldo.
3. Selecciona la **forma o formas de pago** (se permite pago mixto).
4. Si aplica, divide la cuenta en partes.
5. Confirma el cobro: se genera la **venta** y el **comprobante fiscal**.

## Cerrar caja

1. Al terminar el turno, inicia el **cierre**.
2. Realiza el **arqueo** contando billetes y monedas por denominación.
3. El sistema muestra la diferencia entre lo esperado y lo contado.
4. Confirma para emitir el **reporte de cierre (Z)**.
