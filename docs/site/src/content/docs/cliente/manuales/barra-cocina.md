## Pantalla de comandas (KDS)

- Las comandas llegan **en tiempo real** a tu pantalla.
- Cada ítem muestra el producto, la cantidad y la mesa de origen.

## Estados de un ítem

1. **Recibido** — la comanda llegó al área.
2. **Preparado** — el producto está listo.
3. **Entregado** — el mesero lo retiró.

## Recomendaciones

- Actualiza el estado en cuanto cambie para que el mesero y la caja vean la información.
- Si un producto no está disponible, márcalo para avisar al mesero.
- En barra, revisa las **recetas** de cócteles y tobos para descontar correctamente los
  insumos.
