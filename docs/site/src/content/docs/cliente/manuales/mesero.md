---
title: Manual del mesero
---

## Abrir una mesa

1. En la vista **Mesas**, toca la mesa que vas a atender.
2. Si el cliente tiene **reserva**, selecciónala para cargar lo que ya pidió.
3. Confirma la apertura: se crea la cuenta de la mesa.

## Tomar el pedido

1. Busca el producto por nombre o código de barras.
2. Agrega los ítems; el sistema los envía automáticamente a **barra** o **cocina**.
3. Puedes seguir agregando ítems durante la estadía.

## Cargar una reserva

- El sistema muestra el **paquete reservado**.
- Marca lo **entregado** y lo que **falta por entregar**.
- Si el cliente pide algo más, agrégalo con normalidad.

## Reportar un producto dañado

1. Abre la opción **Merma** en la mesa.
2. Indica el producto y la cantidad dañada.
3. Si se repone sin cobro, el sistema agrega la reposición a precio **cero**.

## Ver el total

- En cualquier momento puedes ver el **total consumido**, lo **abonado** y el **saldo**.
- Cuando el cliente esté listo para pagar, avisa al **cajero** o lleva la cuenta a caja.
