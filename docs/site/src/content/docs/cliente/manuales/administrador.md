## Configuración inicial

1. Carga el **catálogo**: categorías, marcas, productos y variantes con precios.
   - Indica el **área destino** (Barra/Cocina) de cada producto para que las comandas
     se enruten solas.
   - En comida no hace falta grado alcohólico ni código de barras, y el **SKU** se
     autogenera si lo dejas vacío (ej. `TACOS-1`).
2. Define las **zonas** y diseña el **plano** del local (mesas y capacidad).
3. Registra las **tasas de cambio** del día.
4. Crea los **usuarios** y asígnales su **rol**.

## Operación diaria

- **Reservas:** valida las señas y gestiona las reservas del día.
- **Mesas:** supervisa la ocupación en tiempo real.
- **Inventario:** revisa existencias y alertas de stock mínimo.
- **Mermas:** controla el reporte de pérdidas.
- **Caja:** verifica el cierre del turno.

## Contenido de la web pública

- Publica **eventos** y actualiza secciones.
- Genera el **menú digital (QR)** y el menú **físico (PDF)**.
- La IA puede proponer secciones; **aprueba** antes de publicar.

## Tablero de KPIs

Consulta ventas, ocupación, ticket promedio, productos más vendidos, reservas y mermas
para tomar decisiones.

## Plano con IA

Puedes subir una **foto de un croquis en papel** y el sistema propone el plano con
zonas, mesas y sillas; luego lo ajustas y confirmas.
