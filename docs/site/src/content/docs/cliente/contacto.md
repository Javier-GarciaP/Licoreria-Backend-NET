## WhatsApp

El medio más rápido para contactarnos es **WhatsApp**. En la web pública encontrarás un
botón que abre el chat con un mensaje precargado; solo debes enviarlo.

Puedes escribirnos para:

- Consultar disponibilidad de mesas.
- Reservar por WhatsApp.
- Consultar eventos y promociones.
- Resolver dudas sobre pagos y señas.
