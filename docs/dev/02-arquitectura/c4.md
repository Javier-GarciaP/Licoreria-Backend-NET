## Nivel 3 · Componentes del backend

```mermaid
flowchart LR
    subgraph WebAPI
        Ctrl[Controladores]
        Mid[ExceptionMiddleware RFC 7807]
        Sec[Auth JWT]
    end
    subgraph Application
        UC[Casos de uso]
        IRepo[Interfaces de repositorio]
        ISvc[Servicios: IA, Storage, WhatsApp]
    end
    subgraph Infrastructure
        DbCtx[LicoreriaDbContext]
        Repo[Repositorios EF Core]
        AiClient[Cliente IA]
    end
    Ctrl --> UC
    Mid -.-> Ctrl
    Sec -.-> Ctrl
    UC --> IRepo
    Repo -.implementa.-> IRepo
    Repo --> DbCtx
    UC --> ISvc
    AiClient -.implementa.-> ISvc
```
