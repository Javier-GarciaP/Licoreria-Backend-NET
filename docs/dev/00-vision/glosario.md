# Glosario del Dominio

Términos usados a lo largo de la documentación.

| Término | Definición |
| :--- | :--- |
| **Zona** | Área del local (barra pública, mesas, zona de juegos, pista de baile, VIP). |
| **Plano** | Representación gráfica de la distribución del local con zonas y mesas. |
| **Mesa** | Punto de consumo con capacidad (sillas) y posición en el plano. |
| **Sesión de mesa** | Periodo durante el cual una mesa está ocupada por un cliente. |
| **Cuenta** | Acumulado de consumos de una sesión o reserva, con abonos y total. |
| **Comanda** | Pedido que un mesero envía a un área (barra o cocina). |
| **Ítem de comanda** | Línea de una comanda con su estado y área destino. |
| **Tobo** | Envase/contenedor de cervezas (presentación típica del local). |
| **Abono** | Pago parcial aplicado a una cuenta antes de su cierre. |
| **Seña** | Depósito anticipado para confirmar una reserva. |
| **Reserva** | Solicitud de una mesa/zona para una fecha y hora. |
| **Kardex** | Historial de movimientos de inventario de un producto. |
| **Movimiento de inventario** | Entrada, salida, ajuste, transferencia, merma o cortesía. |
| **Merma** | Producto no vendible (dañado, partido o vencido) que se descuenta. |
| **Cortesía** | Producto entregado sin cobro (por ejemplo, reposición de una merma). |
| **Variante** | Presentación vendible de un producto (750 ml, 1 L, tobo, plato). |
| **Receta** | Definición de insumos que consume un producto preparado (cóctel, tobo). |
| **Tasa de cambio** | Valor de conversión USD/BS vigente para una fecha. |
| **Cierre de caja (Z)** | Proceso de cierre de turno con arqueo y consolidado. |
| **Comprobante fiscal** | Documento con número de factura y número de control (SENIAT). |
| **RBAC** | Control de acceso basado en roles. |
| **Design tokens** | Variables de estilo (color, tipografía, espaciado) de la web pública. |
| **UI generativa** | Generación de secciones web a partir de plantillas y contenido por IA. |
